## 🎮 О игре

"Студент: Возвращение в родной город" - это текстовая приключенческая игра с элементами RPG, которая рассказывает историю студента, возвращающегося домой на каникулы. Игрок принимает решения, влияющие на сюжет, играет в мини-игры и собирает артефакты.

**Основные темы:** ностальгия, взросление, взаимоотношения с семьей и друзьями.

## ✨ Особенности

- **Ветвящийся сюжет** - решения влияют на развитие истории
- **Четыре мини-игры** - интегрированные в игровой процесс
- **Система артефактов** - сбор уникальных предметов
- **Авторизация пользователей** - система регистрации и входа
- **Сохранение прогресса** - возможность продолжения игры
- **Множественные концовки** - в зависимости от принятых решений
- **🤖 Поддержка AI-генерации** - автоматическое создание новых артефактов через Ollama

## 🎯 Сюжет

Вы - студент, вернувшийся из Москвы в родной город на зимние каникулы. Поезд прибыл на вокзал, и перед вами стоит выбор:

**🏠 Путь родителей:**
- Чай с мамой
- Анекдоты с отцом (мини-игра)
- Семейный вечер

**👥 Путь друзей:**
- Битва с местным бомжом Виталием (мини-игра)
- Вечеринка на даче
- Камень-ножницы-бумага (мини-игра)
- Визит к бабе Зине (21 спичка - мини-игра)

## 🎮 Игровой процесс

### Основные механики:
- **Здоровье (HP)** - уменьшается при ошибках, восстанавливается при правильных решениях
- **Уважение отца** - зарабатывается за успехи в анекдотах
- **Уровень опьянения** - влияет на восприятие диалогов
- **Квесты** - 6 основных заданий для завершения игры

### Ключевые решения:
1. Куда пойти сначала: к родителям или друзьям?
2. Пить ли мамин чай?
3. Играть ли в анекдоты с отцом?
4. Выпить ли зелье здоровья на даче?

## ⚙️ Установка и запуск

### Требования:
- Python 3.8 или выше
- Никаких дополнительных библиотек не требуется (кроме requests для AI-функций)

### Установка:

1. **Скачайте все файлы проекта** в одну папку:
   - `game.py`
   - `student_game.py` 
   - `user.py`
   - `auth.py`
   - `qwests.py`
   - `battle.py`
   - `artifacts.py`
   - `artifacts.json` (может быть создан автоматически)

2. **Установите зависимости для AI-функций (опционально):**
```bash
pip install requests
```

3. **Запустите игру:**
```bash
python game.py
```

Или если вы используете Python 3:
```bash
python3 game.py
```

### Первый запуск:
1. При первом запуске создастся файл `users.json`
2. Пройдите регистрацию (придумайте логин и пароль)
3. Начните игру с вокзала

## 🤖 Интеграция с Ollama AI

### Для чего это нужно:
**🤖 Автоматическая генерация новых артефактов** значительно улучшает игровой опыт, особенно при многочисленных прохождениях:
- **Увеличивает реиграбельность** - каждый раз новые уникальные артефакты
- **Расширяет контент** - без ограничений ручного создания
- **Персонализирует опыт** - артефакты генерируются под конкретные темы
- **Снижает повторяемость** - игра остается свежей после многих прохождений

### Как подключить AI-генерацию:

1. **Установите Ollama:**
   - Скачайте с [официального сайта](https://ollama.com/)
   - Установите на свой компьютер

2. **Запустите сервер Ollama (в отдельном терминале):**
```bash
ollama serve
```

3. **Загрузите модель (в другом терминале):**
```bash
# Рекомендуемые модели для русского языка:
ollama pull qwen2:1.5b      # Маленькая и быстрая
# или
ollama pull phi3:mini       # Лучшее качество русского
```

4. **Включите AI-генерацию в игре:**
   - При создании нового артефакта игра автоматически запросит у AI новое описание
   - AI будет генерировать уникальные артефакты на основе темы
   - Все сгенерированные артефакты сохраняются в `artifacts.json`

### Функции AI-интеграции (в `artifacts.py`):
- **Автоматическая генерация** новых артефактов
- **Валидация и форматирование** AI-ответов
- **Кэширование результатов** для офлайн-работы
- **Резервное копирование** существующих артефактов

### Пример работы AI-генератора:
```python
# При вызове функции очистки:
artifacts.clear_artifacts("чаепитие")

# Артефакт будет очищен, а AI вернет ему замену, соответствующую тематике:
{
  "theme": ["Зачетка первого курса"]
}
```

## 💾 Система сохранения

### Автоматическое сохранение:
- При завершении игры
- При выходе через меню
- Сохраняется в `quicksave.json`

### Что сохраняется:
- Прогресс истории
- Собранные артефакты (включая AI-сгенерированные)
- Полученные достижения
- Здоровье и характеристики
- Выполненные квесты

### Пользовательские данные:
- `users.json` - логины и пароли пользователей
- `artifacts.json` - база данных артефактов (ручных и AI-сгенерированных)

## 🎭 Мини-игры

### 1. **Анекдоты с отцом** (в `qwests.py`)
- **Цель:** Правильно закончить анекдоты
- **Особенность:** Несколько вариантов правильных ответов
- **Награда:** "Уважение отца" + артефакт

### 2. **Камень-ножницы-бумага** (в `qwests.py`)
- **Цель:** Выиграть у компьютера
- **Управление:** Выбор 1-3
- **Награда:** Артефакт "Честь"

### 3. **21 спичка** (в `qwests.py`)
- **Цель:** Не брать последнюю спичку
- **Правила:** Брать 1-3 спички за ход
- **Использование:** С бабой Зиной за пиво

### 4. **Битва классов** (в `battle.py`)
- **Цель:** Победить бомжа Виталия
- **Классы:** Воин, Маг, Лучник
- **Механика:** Пошаговая битва с характеристиками

## 🏆 Артефакты

### Базовая коллекция:
- **Использованный пакетик Greenfield** - от маминого чая (+5 HP)
- **Уважение отца** - за успех в анекдотах
- **Чекушка** - трофей за победу над Виталием
- **Честь** - за победу в камень-ножницы-бумага
- **Чирик из старой куртки** - выигран у бабы Зины

### AI-генерация артефактов:
```python
# Файл artifacts.py предоставляет функции:
from artifacts import generate_ai_artifact, load_artifacts, save_artifact

# Генерация нового артефакта через AI
new_artifact = generate_ai_artifact("зимние каникулы")
# Загрузка всех артефактов
all_artifacts = load_artifacts()
# Сохранение нового артефакта
save_artifact(new_artifact)
```

### База артефактов:
Все артефакты хранятся в `artifacts.json` в формате:
```json
{
  "Название темы\квеста (theme)": ["Имя артефакта"]
}
```
